# Volunteer Fire Department Security Architecture

## Scenario

Secure a 200-member volunteer fire department using Microsoft security technologies.

## Technologies

- Microsoft Entra ID
- Multifactor Authentication
- Conditional Access
- Microsoft Intune
- Defender for Office 365
- Defender XDR
- Microsoft Sentinel

## Objectives

- Protect identities
- Secure email
- Protect endpoint devices
- Monitor security events
- Improve governance

## Project Deliverables

- Security Architecture Diagram
- Conditional Access Strategy
- MFA Deployment Plan
- Device Management Plan
- Incident Response Playbook
- Security Monitoring Design
- Executive Briefing
