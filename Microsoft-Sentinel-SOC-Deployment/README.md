# Microsoft Sentinel SOC Deployment

## Scenario

Design a Security Operations Center (SOC) for a volunteer fire department using Microsoft Sentinel.

## Objectives

- Collect and analyze security logs
- Detect suspicious activity
- Create incident response workflows
- Provide visibility into security events
- Improve threat detection and investigation

## Technologies

- Microsoft Sentinel
- Log Analytics
- Microsoft Defender XDR
- Microsoft Entra ID
- Microsoft 365

## Project Deliverables

- Sentinel Architecture
- Data Connector Strategy
- Incident Workflow
- KQL Query Library
- Executive Dashboard
