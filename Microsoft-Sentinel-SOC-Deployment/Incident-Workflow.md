# Incident Workflow

## Detection

Event generated in Microsoft Sentinel.

## Triage

Determine:

- Severity
- Impact
- Scope

## Investigation

Review:

- Sign-in activity
- Device activity
- Email activity

## Containment

- Disable account
- Isolate device
- Block malicious sender

## Recovery

- Restore access
- Validate controls
- Monitor activity

## Lessons Learned

- Update detections
- Improve training
- Adjust security controls
