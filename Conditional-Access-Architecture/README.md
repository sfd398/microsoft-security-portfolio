# Conditional Access Architecture

## Scenario

Design Conditional Access policies for a volunteer fire department with approximately 200 users.

## Goals

- Protect user identities
- Reduce account compromise risk
- Enforce multifactor authentication
- Block legacy authentication
- Protect privileged accounts

## Technologies

- Microsoft Entra ID
- Conditional Access
- Multifactor Authentication
- Identity Protection
- Privileged Identity Management

## Project Deliverables

- Conditional Access Policy Matrix
- Named Locations Design
- Administrator Protection Strategy
- Break Glass Account Strategy
- Rollout Plan
