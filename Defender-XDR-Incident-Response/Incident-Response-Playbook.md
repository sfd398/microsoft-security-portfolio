# Incident Response Playbook

## Phishing Email Scenario

### Detection

Alert generated by Microsoft Defender for Office 365.

### Investigation

Review:

- Message trace
- Recipient list
- URL clicks
- Sign-in logs

### Containment

- Remove malicious messages
- Reset affected passwords
- Require MFA re-registration

### Recovery

- Restore user access
- Verify endpoint health
- Increase monitoring

### Lessons Learned

- Identify training opportunities
- Update detection rules
- Improve Conditional Access policies
